# Carbon Footprint Calculator for AI Models — Daniel Ojeda Rosales

Upload one or more run folders (as ZIPs). Each run folder must include:
- summary.json
- epochs.csv
- samples.csv
- emissions.csv

Use the tabs to:
- View a baseline dashboard (single run)
- Compare ONLINE vs OFFLINE (Korea) when both runs are uploaded
- Explore Region & PUE sensitivity for KOR, CAN, MEX, MNG
- Overlay multiple runs for general comparison
